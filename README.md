# Portfólio

Portfólio pessoal em estilo terminal (HTML, CSS e JavaScript puro) que apresenta o desenvolvedor de forma interativa, simulando comandos digitados em um terminal Linux. Voltado para quem quer exibir projetos, habilidades e contatos com um visual retrô e minimalista.

## Funcionalidades

- Tela de boot animada na abertura.
- Efeito de digitação dos comandos, como em um terminal real.
- Lista de projetos com links para visita.
- Seções de sobre, habilidades e contato.
- Relógio de "uptime" atualizado em tempo real.
- Efeitos de glitch e partículas flutuantes.
- Tema monocromático rosa/escuro com fonte JetBrains Mono.

## Projetos

- [FOCO](https://klcombr.github.io/foco/) — site de estudos monocromático e minimalista: pomodoro, metas diárias, streak, XP, níveis e conquistas. Pensado pra incentivar consistência.
- [schoolflow](https://github.com/klcombr/schoolflow) — saas de gestão operacional para escolas.
- [PDFinder](https://klcombr.github.io/PDF/) — buscador de PDFs online.
- [Serpentia](https://github.com/klcombr/Serpentia) — laboratório de código interativo.
- [Opallium](https://klcombr.github.io/Opallium/) — seu workspace, sua estrutura, seu código.
- [Price Calculator](https://propricalc.netlify.app/) — ferramenta web minimalista.
- [NewWay](https://github.com/klcombr/NewWay) — otimizador de windows em python.

## Como usar

Abra o arquivo `index.html` no navegador. Nenhuma instalação ou servidor é necessário.
